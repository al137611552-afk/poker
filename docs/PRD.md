# 需求文档（PRD）

完整设计方案（含调研、架构图、硬件档位、里程碑）见
<https://claude.ai/code/artifact/9a1d285c-c5e6-4613-90ef-f83507b04b2b>。
本文件只保留可验收的需求条目。

## 定位

本地运行的德州扑克训练与复盘系统。**仅用于离线训练**，不提供任何接入真钱平台的
实时辅助接口。

## 已定方向（2026-08-17）

| 项 | 决定 |
|---|---|
| 主线玩法 | 六人现金局；单挑仅作强度校准场 |
| 部署形态 | 电脑跑本地服务端，手机浏览器/PWA 作客户端 |
| 计算路线 | 翻后求解走 **CPU 版 TexasSolver**（GPU 版无命令行/API，用不了；见 [ADR-0005](adr/0005-postflop-solver-backend.md)）；求解器不随包分发，用户自行安装 |
| 交付顺序 | 先对战、后复盘 |

## 非功能需求

- **可复现**：任意一手牌可由 (种子, 手数) 精确重放。
- **离线**：除可选的 Slumbot 基准调用外，全程不联网，牌谱不出本机。
- **跨端**：手机浏览器可完成全部「玩与看」的操作，重计算一律落在服务端。
- **诚实**：非求解得出的建议必须在界面上标注置信度，不得冒充精确解。
