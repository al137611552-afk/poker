# ADR-0003：深筹码翻前范围怎么来——自解抽象树 + 翻后压缩模型

- 日期：2026-08-17
- 状态：已接受（第一段实现完成：单挑可解；六人桌待续）

## 背景

M1 要给出六人桌 100bb 的翻前范围（开牌、面对开牌、3bet、防守）。推/弃能精确求解，是因为
短筹码下动作只有两个、牌局到摊牌就结束（ADR-0001 的延伸，见 `pushfold.py`）；100bb 完全
不同：「跟注去看翻牌」的价值取决于翻后三条街怎么打，翻前无法直接算。

## 备选方案

| 方案 | 内容 | 结论 |
|---|---|---|
| A **自解抽象翻前树** | 下注序列离散化后展开成树，用 CFR+ 求解，翻后压缩成一个终局收益模型 | **采用** |
| B 规则构造 + 频率校准 | 用权益表加可玩性打分给 169 个牌类排序，各位置按目标开牌频率切阈值 | 一天能做完，但没有均衡意义，M3 复盘不能拿它当标尺 |
| C 抄公开 GTO 图表 | 直接把网上的范围表录进来 | 与 M1 第二段的教训冲突（公开表实测串行、出错），且 GTO Wizard 的 ToS 明令禁止（ADR-0002） |

选 A 的关键理由是**可自证**：解完能算可利用度，能退化成已知解交叉验证；B 和 C 都只能
「看起来像」，出了错没有内部办法发现。

## 决策

### 1. 翻前树完整展开，翻后压缩成一个数

树里保留全部下注序列（`preflop_tree.py`），下注尺度离散化为：开牌 2.5bb（每个跛入者 +1bb）、
3bet ×3、4bet ×2.2、再往上只剩全下。有效筹码相等，因此不必处理边池。

终局分三类，**只有第三类是近似的**：

- 只剩一人 → 纯筹码搬运，精确。
- 全下被跟 → 直接查翻前权益表，精确。
- 进翻牌 → 走权益兑现模型（`realization.py`）。

### 2. 翻后模型：归一化的权益兑现

```
share_hero = (R_hero · eq)^γ / ((R_hero · eq)^γ + (R_villain · (1 − eq))^γ)
R = 位置基准 + 牌型修正 × min(1, SPR / 参考 SPR)
γ = 1 + 锐化系数 × min(1, SPR / 参考 SPR)
```

两条设计取舍：

- **写成归一化比值而不是 `R · eq · P`**，是为了让终局严格零和。筹码守恒是可测试的硬性质，
  不守恒的终局会让求解器凭空造钱、EV 全不可信。代价是 `R` 只有相对意义。
- **γ（锐化）不是装饰，是修一个真错**。第一版只按权益分池，解出来 SB 面对 3bet 只弃 26.7%，
  大盲面对开牌只弃 11.3%——因为模型认定「有 30% 权益就能拿 30% 底池」。真实牌局里弱牌的
  权益集中在少数牌面上，多街下注中多半要弃牌，公开求解器里体现为强牌兑现超过 100%、
  弱牌不足 70%。加上 γ 之后两个数字变成 43.0% 和 30.7%，与常识量级吻合。

### 3. 参数是假设，必须标注

`RealizationModel` 的默认值取自公开求解器的常识量级（位置差约 10 个百分点、修正项几个
百分点、γ 约 1.35），**没有经过本项目的实测校准**。因此：

- 测试只验性质（守恒、单调、退化），不把任何具体数字钉成基准；
- 参数集中在一个 dataclass 里，可整体替换；
- 校准计划：用 Slumbot 免费 API 打单挑实测（ADR-0002 已定的外部标尺），反推兑现系数。
  这是 M1 后续的一段，**在校准之前，界面上的翻前建议只能标 C 级（启发式），不能标 A 级**。

### 4. 正确性怎么保证

不依赖任何外部数据，两条：

1. **可利用度自证**：解完对双方各算一次最佳应对，看还能多赚多少（大盲/手）。
2. **退化交叉验证**：把开牌尺度设成全部筹码、关掉跛入，树就退化成推/弃博弈，解必须与
   `pushfold.solve_push_fold` 这套独立实现对上。实测总频率差 0.1 个百分点以内、
   小盲 EV 差 4e-5 bb/手。这一条同时验证了树、终局收益、共牌处理与 CFR+ 实现。

## 已知限制

- **多人桌尚未支持**。多人终局要在三个以上对手的联合分布上积分（共牌与多人权益都是另一
  码事），求解器遇到多人配置直接报错，不假装能算。
- **完整六人树有 62 万个节点**（单挑只有 40 个），纯 Python 的向量 CFR 跑不动。六人桌那段
  必须先裁剪（关跛入、减少加注层级）或按位置分解子博弈，这是那一段要先解决的问题。
- **兑现系数不区分牌力档位**，只按位置、牌型、SPR 取值；γ 承担了「强弱牌兑现不同」的作用，
  但它是全局的，不区分具体牌面。
- **不含跨手牌因素**：没有前注结构变化、没有对手倾向、没有筹码不等。
- 收敛速度大致 O(1/t)：完整单挑树 1500 次迭代（约 75 秒）到 0.0026 bb/手。要更低只能靠
  更多迭代，或把树裁小。

- 新增 `preflop_tree.py` / `realization.py` / `preflop_solver.py`，55 个新单测。
